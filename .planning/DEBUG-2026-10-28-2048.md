# Debug Report — 2026-10-28

**Symptom:** Rafa repeatedly answered an Arabic company-formation question with a generic temporary-failure message.
**Scope:** Local REFAL worker, real WhatsApp chat, configured DeepSeek V4.1 Flash model.

## Root cause

The restarted local worker processed a real WhatsApp turn and completed five Agent steps. The first two answer drafts were rejected only for `too_many_sentences`; the final turn ended as `response_rejected` with `terminationCause=too_many_sentences`. The drafts were about 1,140 characters with 14 sentence-ending marks. The Knowledge Gap recorder captured the same turn as `agent_failure / too_many_sentences`, confirming that gap capture was working.

The Agent decision prompt gave ordinary replies the expanded budget of up to 12 sentences and 1,800 characters. The runtime also used that expanded limit for every production answer because the semantic grounding assessor is always enabled. A question asking for the first setup step consequently received a long package overview; the model slightly exceeded the limit, repeated the same style after rejection, then fell back to the generic failure.

## Fixes applied locally

- `src/responsePolicy.js`: ordinary answers now use the standard 5-sentence / 700-character budget. The 12-sentence / 1,800-character budget is selected only when the customer explicitly asks for details, a breakdown, or package inclusions in Arabic, English, or Greek.
- `src/agentDecision.js`: the prompt now matches the chosen response budget and tells the Agent to answer a first-step question with that step only, without adding an unrelated package catalogue, price, timeline, document checklist, or guarantee.
- `src/agentLoop.js`: response validation now selects the same explicit-request budget.
- `src/contextualPreflight.js`: any classifier-provider error falls back to deterministic intent classification while forcing workflow operation and consent to `none`; the measured HTTP status is logged without provider message text.
- Updated the known-defect harness so it no longer repeats stale claims about the model key, identity answer, or consent-table policies.
