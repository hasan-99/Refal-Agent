# Debug Report — 2026-10-10 23:42

**Symptom:** REFAL answered the Arabic question `بتحكي انكليزي` in English, and failed to answer `طيب كيف فينا نبلش` after a company-registration discussion.
**Mode:** general

## Investigation

- Traced language detection, intent classification, deterministic routing, and the Agent's initial approved-knowledge retrieval.
- Reproduced the language result: `detectExplicitLanguageRequest` interpreted asking whether REFAL speaks English as an instruction to switch to English, overriding Arabic script detection.
- Reproduced the follow-up result: the short question was `unknown`, so the Agent's retrieval gate skipped the previous company-formation conversation.
- Ran a no-send Agent replay with the exact prior company-registration exchange. It retrieved approved company-lifecycle knowledge and generated an Arabic response with an actionable first step and one question.

## Root Cause

- `src/language.js` treated Arabic language-capability questions as explicit language-switch commands, so the router persisted the wrong language and replied in English.
- `src/agentRuntime.js` only initiated approved-knowledge retrieval for the current message's recognized factual intent; it discarded useful recent context for ambiguous follow-ups.

## Fix Applied

- Separated Arabic language-capability questions from explicit requests to switch language; added a localized, deterministic language-capability response and regression coverage.
- When a short current turn has no factual intent but the most recent customer turn did, the Agent now searches with the recent conversation text and current question. No fixed follow-up phrases or business keyword lists are added.
- Regenerated the Edge language mirror so source and generated policy remain byte-identical.
- Verification: focused language/router/runtime tests passed; `npm run test:all` passed (2,019 Node tests and 105 dashboard tests); `git diff --check` passed; an isolated production-knowledge replay returned grounded Arabic output. No WhatsApp message was sent.
