# Debug Report — 2026-10-02 19:37 UTC

**Symptom:** The Follow-ups sidebar badge showed three while the queue grouped the same contact into one item.
**Mode:** general

## Investigation
- Inspected `dashboard/server.js` summary endpoint and `dashboard/src/main.jsx` badge consumer.
- Checked the active handover records in Supabase read-only; three open handover rows belonged to one contact.
- Confirmed the inbox applies contact grouping, but the summary API previously returned `openRows.length`.

## Root Cause
`dashboard/server.js` — `/api/handovers/summary` counted handover rows rather than distinct contacts, so its badge diverged from the grouped inbox.

## Fix Applied
- `dashboard/handoverGrouping.js`: added unique-contact counting shared by the badge logic.
- `dashboard/server.js`: fetches only handover and contact IDs for the badge and counts unique contacts.
- `dashboard/handoverGrouping.test.js`: regression coverage for multiple active requests from one contact.
- Verification: dashboard tests pass (63/63), server syntax check passes, production build passes.
