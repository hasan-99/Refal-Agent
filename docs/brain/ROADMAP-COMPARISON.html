But Codex has a real point, and you should hear it. Cyprus corporate tax was 12.5% for many years. Your manual says 15% from 2026. That is plausible, but if it is wrong, Plan A confidently tells every customer a wrong tax rate in three languages. Plan B would have caught it.

The fix is not to choose. State the facts (Plan A), but attach Plan B's approval metadata to each one: source, reviewer, effective date, expiry. Then a wrong number is corrected with one data edit, not a code release, and she stops saying it automatically when it expires.
